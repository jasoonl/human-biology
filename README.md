# Interactive 3D Human Body Explorer

A classroom teaching tool for AP Biology, built in Unity 6 (URP). Explore a full 3D human body, male or female, with and without skin.

## Features

- **Click to learn**: select any bone, muscle, organ, vessel or nerve and read about it at three levels of detail.
- **Peel the layers**: show or hide body systems one at a time, from skin down to skeleton.
- **Male and female figures**: sex-specific face, hair, body shape and reproductive anatomy.
- **Identification quiz**: timed questions with spaced-repetition scoring.
- **Isolate mode**: the selected structure glows while everything else fades to a translucent ghost.

## Requirements

- Unity **6000.6.0f1** (Apple Silicon, Universal Render Pipeline)

## Getting started

1. Open the project folder in Unity Hub with the version above.
2. Open `Assets/Scenes/Bootstrap.unity` and press Play.

The scene is generated by code, not hand-authored. To change the figure or UI, edit the generators in `Assets/Editor/` (see `HumanBodyExplorerSetup.cs` and `Assets/Editor/Geometry/`) and rebuild from the **Human Body Explorer** menu. Hand edits to the scene are overwritten on the next build.

## Tests

```bash
UNITY=/Applications/Unity/Hub/Editor/6000.6.0f1/Unity.app/Contents/MacOS/Unity
"$UNITY" -batchmode -nographics -runTests -testPlatform EditMode -projectPath "$PWD" -testResults /tmp/editmode.xml -logFile /dev/stdout
```

Close the Unity Editor first, since it locks the project. See `CLAUDE.md` for the full set of commands.

## Project layout

| Path | Contents |
| --- | --- |
| `Assets/Editor/` | Scene and geometry generators (SDF meshing, lofted tubes) |
| `Assets/Scripts/` | Runtime code: selection UI, quiz, layers |
| `Assets/Shaders/` | Skin, outline and blood-flow shaders |
| `Tools/ZAnatomy/` | Scripts that export and map the Z-Anatomy atlas |
| `Planning.md` | What is built versus deliberately stubbed |
